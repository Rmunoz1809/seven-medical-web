# SEVEN Medical Company — sitio web

Sitio estático de SEVEN Medical Company, distribuidor exclusivo de Mindray en Panamá.

- `index.html` — inicio
- `nosotros.html`, `productos.html`, `producto.html`, `contacto.html`
- `assets/css/seven.css` (sistema de diseño), `assets/css/home.css` (inicio)
- `assets/js/data.js` (catálogo de equipos), `assets/js/seven.js`, `assets/js/home.js`
- `images/` — equipos, fotos clínicas y galería de imagen

Para verlo, abra `index.html` en el navegador. No necesita compilación.
